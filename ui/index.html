Parameters & Layout

Play-mode controls and VST automation

Declaration

p_name = param(default, minimum, maximum, step)

p_ は必須です。値は式にそのまま渡されます。step は省略でき、0 なら連続値です。使う式より前に宣言してください。

Meaningful ranges

演奏者が期待する変化と、名前・式の意味を揃えます。たとえば秒単位の p_release_s を使い、exp(-8 * l / p_release_s) と書けば、値を大きくするほどリリースが長くなります。

Placement

  1. Arrange を開きます。
  2. コントロールをドラッグして移動します。
  3. 右下のハンドルをドラッグしてサイズを変更します。
  4. Arrange を終了すると、位置がVSTプロジェクトに保存されます。

Right-click & automation

コントロールを右クリックすると、リセット、値のコピー・貼り付け、ノブ・スライダー・トグルの選択ができます。宣言順がVSTオートメーションの順番になります。コメント付きDSLで同じ説明を見るには Parameter Guide を読み込んでください。

Editor Guide

Synth DSL and live preview

Write an expression

音声の式を1行ずつ記述します。左側に名前、右側に式を書き、必ず wave と l_limit へ出力してください。

wave = s * sin(TAU * freq * t)
l_limit = 1.0

Inputs and outputs

t、l、freq、s などの入力は補完とHoverで確認できます。wave と l_limit は必須、pan は任意の出力です。l_limit はノートを離してからボイスを終了する秒数です。

Compile and preview

Compile または Ctrl+S で式を検証します。Preview または Ctrl+Enter で現在のノートを試聴できます。エラー表示をクリックすると該当位置へ移動します。ローカル変数や式が大きい場合もコンパイルは継続し、CPU 負荷に影響し得る場合だけ Warning を表示します。

Parameters

Play modeの操作子を作るには、式より前に p_name = param(default, min, max, step) を宣言します。配置やVSTオートメーションはPlay modeのGuideで確認できます。
